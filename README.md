🤖 Cybele
Cybele is a Python-based chatbot focused on curated knowledge and functional tools. Featuring a retro design, it operates offline and is portable (compatible with Android/iOS via a Python 3.10+ interpreter).

📊 Data Updates
The database is updated weekly and monthly using data from the Atlantic Meridional Overturning Circulation (AMOC) sourced from IFREMER, serving to keep the script operational.

🚀 How to Run:

On Windows:
Locate and run the `run.bat` file in the main folder.
If prompted about missing libraries, type 'y' to allow automatic installation.

On Linux:
Open the terminal in the project folder.
Grant execution permission: `chmod +x run.sh`
Run: `./run.sh`

📁 Project Structure
/src: Core logic (cybele.py)
/assets: Visual assets and icons
run.bat / run.sh: Startup scripts.
